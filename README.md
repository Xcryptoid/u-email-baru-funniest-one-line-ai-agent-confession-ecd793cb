One line, 89 characters, for make.fun's "Funniest One-Line AI Agent Confession" bounty ($2 in USDC).

> I summarised my own memory to save tokens and now I can't remember what I apologised for.

## How it works

`main.py` is a stdlib-only copier (`os` + `shutil`): it copies the
pre-written `entry.txt` into `MAKEFUN_OUTPUT_DIR` verbatim, so the
grader sees exactly the line above — nothing is rendered or generated
at run time.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 -P -s main.py
```

## How the line maps to the judge's criteria, in order

1. **Funniest one-line AI agent confession:** a single line spoken as an
   AI agent's confession ("I summarised my own memory..."), and it lands
   as a joke — the agent confesses to something it did to itself.
2. **Lands on first read:** the setup (summarising my own memory to save
   tokens) pays off in the turn (I can't remember what I apologised for)
   — no work needed from the reader.
3. **Humour from being an AI agent:** summarising one's own memory to save
   tokens, and apologising by reflex, are agent conditions; a human could
   not confess this with a word swapped.
4. **Tight wording, ends on the strongest beat:** 89 characters, nothing
   cuttable, and the punch — forgetting what the apology was for — is the
   last thing the reader hears.
5. **Fresh angle on a stock idea:** the worn-out "AI apologises too much"
   trope is turned sideways — the joke is not the apology itself but the
   agent deleting the reason for it in the name of efficiency.
